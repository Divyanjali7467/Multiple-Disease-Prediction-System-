# 🩺 Multiple Disease Prediction System
## 🚀 Live Demo

[Multiple Disease Prediction System](https://divyanjali7467-multiple-disease-pred-multiplediseasepred-tqkc0r.streamlit.app/)

## 📖 About the Project

Multiple Disease Prediction System is a Machine Learning-based web application that predicts the likelihood of Diabetes, Heart Disease, and Parkinson's Disease based on user-provided medical parameters.

The application uses trained Machine Learning models and provides an interactive interface built with Streamlit.

## 🛠️ Tech Stack

- Python
- Machine Learning
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## 📌 Features

- 🩺 Diabetes Prediction
- ❤️ Heart Disease Prediction
- 🧠 Parkinson's Disease Prediction
- 🤖 Machine Learning-based predictions
- 🌐 Interactive Streamlit web application



## 📊 Prediction Pipeline

```text
User Input
    ↓
Feature Collection
    ↓
Trained ML Model
    ↓
Prediction
    ↓
Disease / No Disease
```

## 🔐 Machine Learning Models

The application uses trained `.sav` models for:

- 🩺 Diabetes
- ❤️ Heart Disease
- 🧠 Parkinson's Disease
